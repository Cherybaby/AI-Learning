Attention (Seq2Seq Transformer Encoder-Decoder) 网络架构说明

对应代码：Suspension_AI_Design/训练推理/Attention/train_nn_attention.py
本文档描述的所有维度、参数量、指标均来自已训练模型的真实 checkpoint
（nn_out_attention/model.pt 的 ckpt['arch'] + 重建模型后 named_parameters()
的真实 shape，以及 nn_out_attention/metrics.json 的真实训练结果），非凭空推算。

⚠️ 代码中定义了两套架构（Seq2SeqAttnKC=v1、Seq2SeqAttnKC_V2=v2），
当前 checkpoint 实际保存的是 v1（arch_version='v1'），本文档以 v1 为主，
第7节单独说明 v2 的差异。

1. 任务定义

用 33 维硬点坐标 + 完整的 101 步 wc_stroke 序列，一次性并行预测 8 条运动学
曲线（每条曲线 101 个点），是序列到序列（Seq2Seq）任务，不是逐行独立回归——
这是与 MLP 版本（train_nn.py）最本质的区别。

项目 值
硬点输入维度 33（Encoder输入）
stroke 序列长度 T 101（范围 [-50, 50] mm）
输出维度 8 条曲线 × 101 个点
样本粒度 每条几何是一个样本（不是每个 stroke 点）
训练样本数 1896 条几何曲线（异常过滤后，原始1963条剔除67条）
模型类型 Seq2SeqAttnKC（v1，当前 checkpoint 实际使用的版本）
集成 无（单模型，不同于 MLP 版本的5模型集成）

2. 输入构成

2.1 硬点坐标（33维，Encoder输入）

与 MLP 版本相同的 11 硬点 × 3 坐标结构，但 Attention 版本不做逐点分组编码，
33维直接整体送入 Encoder（两层普通 Linear，非 PointMLP 式的逐点独立权重）：

硬点分组 坐标名
O1~O4, S1~S2, U1~U4, R0 共11个硬点 × (x,y,z) = 33维

2.2 stroke 序列（101维，Decoder的query序列来源）

wc_stroke 的完整采样网格（50~150或等效地[-50,50]，101个点），作为 Decoder
每个 query 位置的"位置编码依据"——用 stroke 的数值本身做 sin/cos 位置编码，
而不是用序列下标，因为 stroke 数值在这个任务里才是有物理意义的"位置"。

3. 输出（8维 × 101步）

与 MLP 版本相同的 8 个运动学量：

输出量 说明
toe 前束角 (°)
camber 外倾角 (°)
caster 后倾角 (°)
caster_arm 后倾拖距 (mm)
scrub_radius 主销偏移距 (mm)
tire_con_point_x/y/z 接地点 X/Y/Z (mm)

区别在于：MLP 每次前向只输出某一个 stroke 点的 8 个值；Attention 版本一次
前向输出整条曲线（101个点 × 8个量）。

4. 网络结构（Seq2SeqAttnKC，v1，真实训练超参）

来自 model.pt 的 ckpt['arch']：

n_hp      = 33
n_out     = 8
hidden    = 128      # d_model
n_layers  = 2         # TransformerDecoder 层数
n_heads   = 4         # 多头注意力头数
n_ctx     = 8         # memory token 数量
p_drop    = 0.1

4.1 Encoder：33维硬点 → 8个 memory token

层 维度变换 参数量
encoder.0（Linear+ReLU+Dropout） 33 → 128 weight 4,224 + bias 128 = 4,352
encoder.3（Linear+ReLU+Dropout） 128 → 128 weight 16,384 + bias 128 = 16,512
ctx_proj（Linear） 128 → 1024 weight 131,072 + bias 1,024 = 132,096

ctx_proj 输出的 1024 维立即 .view(B, 8, 128) 拆成 8 个 128 维的 memory
token（这里的 1024 = n_ctx × hidden = 8 × 128，只是一次线性变换同时算出
8个token的实现技巧，1024这个扁平形态不参与后续任何计算）。

memory token 是输入相关的：不同的33维硬点会算出不同的8个token，每次前向
都重新计算，不是训练完固化下来的查表向量。

4.2 stroke 位置编码（Decoder输入的构造）

层 维度变换 参数量
sin/cos 数值位置编码 1 → 64（2×n_freq, n_freq=hidden/4=32） 0（无可学习参数）
pe_proj（Linear） 64 → 128 weight 8,192 + bias 128 = 8,320

每个标准化后的 stroke 标量值，先乘以32个不同频率（torch.exp(torch.linspace(0,4,32))），
分别取 sin 和 cos 拼成64维，再线性投影到128维，得到 tgt（decoder输入，形状
(B, 101, 128)）。v1 版本没有额外的可学习 position embedding（这是 v2 独有的，
见第7节）。

4.3 TransformerDecoder（2层，Post-LN）

nn.TransformerDecoderLayer(d_model=128, nhead=4, dim_feedforward=512,
                            dropout=0.1, batch_first=True, activation="relu")
# 未传 norm_first，默认 norm_first=False，即 Post-LN 结构

每层内部三个子层，Post-LN（先算子层输出，再做残差+LayerNorm）：

Self-Attn:  tgt2 = norm1(tgt  + dropout(SelfAttn(tgt, tgt, tgt)))
Cross-Attn: tgt3 = norm2(tgt2 + dropout(CrossAttn(tgt2, memory, memory)))
FFN:        out  = norm3(tgt3 + dropout(FFN(tgt3)))
子模块 参数 形状 参数量
self_attn.in_proj（Q/K/V合并） weight+bias (384,128)+(384,) 49,152+384=49,536
self_attn.out_proj weight+bias (128,128)+(128,) 16,384+128=16,512
multihead_attn.in_proj（cross-attn的Q/K/V） weight+bias (384,128)+(384,) 49,152+384=49,536
multihead_attn.out_proj weight+bias (128,128)+(128,) 16,384+128=16,512
linear1（FFN第一层） weight+bias (512,128)+(512,) 65,536+512=66,048
linear2（FFN第二层） weight+bias (128,512)+(128,) 65,536+128=65,664
norm1/norm2/norm3（LayerNorm ×3） weight+bias (128,)×2 ×3 128×2×3=768
单层小计 264,576
2层总计 529,152

Self-Attention：101个stroke点互相看（双向，无因果mask，因为整条曲线一次性给定，
不是自回归生成）。Cross-Attention：101个query分别查询8个memory token，注意力
矩阵形状 (B, 4头, 101, 8)，最后一维=8正是memory的长度。

4.4 输出头

层 维度变换 参数量
out_proj（单层Linear） 128 → 8 weight 1,024 + bias 8 = 1,032

v1 版本输出头是单层 Linear（v2 是两层MLP，见第7节）。

4.5 参数量汇总

模块 参数量
Encoder（两层Linear+ctx_proj） 152,960
stroke位置编码（pe_proj） 8,320
TransformerDecoder（2层） 529,152
输出头 1,032
Positional encoding的sin/cos（无参数） 0
总计 691,464

4.6 完整前向数据流

33维硬点 hp                          101个stroke值 stroke_seq
    │                                        │
encoder(2层Linear)                    sin/cos位置编码 + pe_proj
    │ (B,128)                                │ (B,101,128) = tgt
ctx_proj + view                              │
    │                                        │
memory (B,8,128)  ──────┐                    │
                         │                    │
              ┌──────────┴────────────────────┴──────┐
              │  DecoderLayer[0]:                      │
              │   Self-Attn(tgt,tgt,tgt) + norm1       │
              │   Cross-Attn(tgt2,memory,memory)+norm2 │
              │   FFN + norm3                           │
              └──────────────────┬────────────────────┘
                                  │ (B,101,128)
              ┌───────────────────┴────────────────────┐
              │  DecoderLayer[1]: 同上结构（复用同一份memory） │
              └───────────────────┬────────────────────┘
                                  │ (B,101,128)
                            out_proj(128→8)
                                  │
                        输出 (B,101,8)：8条曲线，每条101步

memory（8个token）在2层decoder中保持不变、被反复查询，不会随层数变化而更新。

5. 训练配置

项 值
优化器 Adam，lr=1.5e-3（v1默认），weight_decay=2e-4
学习率调度 ReduceLROnPlateau（验证集平均R²不提升时衰减0.5，patience=4）
损失函数 MSE（标准化空间，对整条曲线所有点、所有量整体计算）
批大小 64（按几何计，每条完整曲线是一个样本）
数据切分 按几何编号切分 train/val/test = 8:1:1（与MLP版本切分逻辑一致，但用的是split_geo而非split_by_group，因为数据已重组为规整序列）
标准化 硬点(xs)、输出(ys)、stroke(ss) 三套独立的z-score标准化器
早停 按验证集平均R²早停，patience=25
随机种子 42
训练方式 整条曲线一次性并行前向，不需要 teacher forcing（区别于早期 GRU 版本需要逐步自回归）

6. 真实训练结果（来自 nn_out_attention/metrics.json）

数据集切分 平均 R²
训练集 0.9714
验证集 0.9550
测试集 0.9479

判据：测试集平均 R² ≥ 0.98 → ⚠️ 未达标（passed: false），低于 MLP 版本
（测试集R²=0.9828，见 MLP/ARCHITECTURE.md）。

此外，经排查（详见前序对话分析），该模型的 Cross-Attention 在部分测试样例上
呈现权重完全均匀分布的现象（各头对8个memory token的权重严格等于1/8），
即模型未学到对不同memory token的区分性查询，这可能是测试集R²低于MLP版本的
原因之一。

7. v2 架构（Seq2SeqAttnKC_V2，代码中已定义但当前checkpoint未使用）

v2 相对 v1 的差异（"方案B"，更大容量+更标准的深层Transformer配方）：

超参 v1（当前使用） v2
hidden (d_model) 128 256
n_layers 2 4
n_heads 4 8
n_ctx（memory token数） 8 4
norm结构 Post-LN（默认，未传norm_first） Pre-LN（显式norm_first=True）
输出头 单层Linear 两层MLP（128→256→8，带ReLU+Dropout）
额外位置编码 无 叠加可学习 pos_query（按序列下标索引，形状(101,256)）
总参数量 691,464 4,745,992

v2 是否比 v1 效果更好，代码注释中明确说明"需要实测（同数据/同预算对比R²/MAE）"，
未给出严格结论。当前保存的 checkpoint 是 v1，若切换到 v2 需用 --arch v2 参数
重新训练。

8. 与 MLP 版本（train_nn.py）的关键差异

对比项 Attention（本文档） MLP（PointMLP，5模型集成）
样本粒度 整条曲线（101点一起并行预测） 逐行独立（每个stroke点是独立样本）
硬点利用方式 整体33维直接过2层Linear，压缩成8个memory token 每个硬点独立小MLP编码后拼接（保留点的身份）
序列结构建模 有（self-attention让曲线内部各点互相感知） 无（stroke当作普通特征输入）
集成 无（单模型） 5个PointMLP取平均
总参数量 691,464 1,797,640（5个成员合计）
测试集平均R² 0.9479（未达标） 0.9828（达标）
